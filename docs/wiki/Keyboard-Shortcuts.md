# Keyboard shortcuts

The keys work anywhere on the library screen, except while you are typing in a field. **Esc** still closes a dialog or clears a search.

The list is in **Settings**, under **Keyboard shortcuts**. **?** opens Settings on that heading.

Point at a control, or tab to it, and a short note says what it does. When that control has a shortcut, the note shows the same key as this list.

| Key | Action |
| --- | --- |
| Ctrl+F or Command+F, or / | Focus search |
| Ctrl+K or Command+K | Find a view, crate, track, or file |
| Up or Down, Enter | Move through the list and open the row |
| Ctrl+1 or Command+1 through 5 | All tracks, Crates, Organize files, History, Backups |
| Esc | Close a dialog, or clear the search |
| Space | Play or pause |
| Left | Back 5 seconds |
| Right | Forward 5 seconds |

On Windows the key is Ctrl. On a Mac it is Command.

Find a view, crate, track, or file scores rail views, crates, and the open library at once, then files on disk. Enter opens the highlighted row. A view opens the same screen as the rail. A crate opens in **Crates**. A track opens in the library. A file opens in **Organize files**. Back restores the previous screen.

Space plays or pauses. Left moves 5 seconds back. Right moves 5 seconds forward.
