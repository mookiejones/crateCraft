# Keyboard shortcuts

The keys work anywhere on the library screen, except while you are typing in a field. **Esc** still closes a dialog or clears a search. **Esc** never quits crateCraft.

Defaults match Serato DJ Pro on a US keyboard. crateCraft has one player, so it uses the left-deck keys. crateCraft extras sit beside those: Space, Left, Right, `/`, Ctrl+K, `?`, and Ctrl+1 through 5.

The full catalog is in **Settings**, under **Keyboard shortcuts**. **?** opens Settings on that heading. Live rows have **Change** and **Reset**. Press the new key after **Change**. A chord another live action already uses is refused. **Reset all** restores Serato defaults plus crateCraft extras. Rows crateCraft cannot run stay listed as **Not in crateCraft**.

Cue pads **1** through **8** jump to that pad. They do not set or delete a cue.

Point at a control, or tab to it, and a short note says what it does. When that control has a shortcut, the note shows the same key as this list.

## Playback

| Key | Action |
| --- | --- |
| W, or Space | Play or pause |
| Alt+Q | Previous track |
| Alt+W | Next track |
| Alt+E, or Left | Back 5 seconds |
| Alt+R, or Right | Forward 5 seconds |
| 1 through 8 | Jump to cue pad 1–8 |
| Shift+Left | Load the selected track |

## Library

| Key | Action |
| --- | --- |
| Ctrl+F or Command+F, or / | Focus search |
| Up or Down, Enter | Move through the list and open the row |
| Ctrl+Shift+Up or Down | Previous or next crate |
| Tab | Reach the drawer, crate list, More, Find, and dialogs |
| Ctrl+R or Command+R | Reveal the track |
| Ctrl+L or Command+L | Locate the playing track |
| Ctrl+A or Command+A | Select all |
| Ctrl+Delete | Remove from the crate |
| Alt+Delete | Remove from the library |
| Ctrl+Shift+Delete | Move the file to Trash |
| + or - | Waveform zoom |

## crateCraft extras

| Key | Action |
| --- | --- |
| Ctrl+K or Command+K | Find a view, crate, track, or file |
| Ctrl+1 or Command+1 through 5 | All tracks, Crates, Organize files, History, Backups |
| Esc | Close a dialog, or clear the search |
| ? | Show this list |

On Windows the key is Ctrl. On a Mac it is Command.

Find a view, crate, track, or file scores rail views, crates, and the open library at once, then files on disk. Enter opens the highlighted row. A view opens the same screen as the rail. A crate opens in **Crates**. A track opens in the library. A file opens in **Organize files**. Back restores the previous screen. Esc from Find or **More** puts the focus back. The first Tab stop is **Skip to content**, which jumps past the bar and drawer.

In **Crates**, the crate list keeps its own keys when that list is focused. Right opens a crate. Left closes it. Those keys are not the seek keys while the crate list has focus.

Space plays or pauses. Left moves 5 seconds back. Right moves 5 seconds forward.
