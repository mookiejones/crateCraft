# Audio changed

**Audio changed** lists a file that was replaced under the same name. Size, length, or a quick hash no longer matches the last check. Cues and the beatgrid may not fit that new audio.

The note under the heading says **A file replaced under the same name. Cues and the beatgrid may not fit. Saving a crate writes the library. Quit Serato first.**

This view covers the whole space. The crate list is hidden. The first time crateCraft sees a file, it remembers that file and does not list it. A later replacement under the same path is listed. A file on an unplugged drive is not a swap.

## Save a crate of replaced files

1. Open crateCraft.
2. Click **Health** in the drawer, then **Audio changed**.
3. The list shows each track whose file changed under the same name, and what changed (size, duration, or quick hash).
4. Click **Save crate**. The page shows the plan. Nothing is written until you confirm.
5. Click **Confirm crate**. Quit Serato first. The crate is named **Audio changed**.

**Check again** reloads the list. A space change or **Reload** does the same.

If the page cannot reach the library server, it says **Couldn't reach the library server. Check it's running, then press Check again**.

When no file changed under the same name, the report says **No file changed under the same name.**

While Serato has the library open, **Save crate** stays off.

## Re-analyze

**Re-analyze** checks whether cues and the beatgrid can move to fit the new audio. It is a preview. crateCraft does not rewrite cues or the beatgrid. The report says **Cues stay put. crateCraft does not rewrite cues or the beatgrid to fit the new audio.**

## Resize the list and the details

This view hides the crate list and the track sheet, so there is no list/details divider here. The width you set in **Crates** is kept for the next time you open a track list.
