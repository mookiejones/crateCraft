# Missing files

**Missing files** lists tracks whose files are missing on a connected drive. The note under the view buttons says **Tracks whose files are missing on a connected drive.** When tracks sit on an unplugged drive, the note says how many, and those rows stay in crates with the word **offline**. They are not listed here, so Relink does not point them at another file.

A missing row shows the word **missing**. An offline row uses a quieter **offline** label, not the missing color.

## Relink missing files

Use this after a drive swap or a folder move, when several tracks went missing at once.

1. Quit Serato DJ Pro. See [Safety and backups](safety.md).
2. Open **Missing files**.
3. Click **Relink missing files**.
4. Search the music folders. After a drive swap, paste the new folder (for example `/Volumes/NEW/DJ`) and click **Find matches**.
5. High-confidence matches are ticked. **Accept all high** ticks the rest. When two files fit, pick one.
6. Confirm **Relink**.

The audio stays where it is. Crates, history, and related links stay attached. The review warns when a new file has no Serato cue tags.

## Point one track at the file

Use this when you already know the new path and the file is still the same recording.

1. Quit Serato DJ Pro. See [Safety and backups](safety.md).
2. Click the track.
3. Click **Relocate**.
4. Paste the full path in **Path to the audio file**.
5. Confirm the prompt.

The page says **File location saved.** **Reveal** stays off until the file is on disk at that path.

**Relocate** and **Relink missing files** do not move the audio. They only change the path stored in the library. To move the file itself, use [Files](files.md).

## Remove the track

1. Click **Remove from library**.
2. Confirm **Remove this track from the library? The audio file stays on disk.**

The row leaves the library. If a file is still on disk somewhere, it stays there. This button does not move a file to the Trash. [Files](files.md) is the view that does that, and only after a review.
