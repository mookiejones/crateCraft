    Tempo drift

    Whole space

    Needs a crate because it decodes audio. Flags a wandering tempo, a live-looking name, or Serato's pending tempo-map mark. A grid that already changes tempo is skipped. This does not rewrite BPM.

    Play stats

    Whole space

    Most played tracks and artists in a period. The idle list can become a crate. Serato must be quit. This report does not change the library until you confirm the crate.

    Library health

    Whole space

    Counts from the library and from audio files on disk. Each row opens the place that can fix it.

    Damaged files

    Whole space

    Quick check reads the start of each file. Full decode needs a crate because it can take minutes.

    Suspect quality

    Whole space

    Needs a crate because it decodes audio. Flags a file whose stated bitrate is much higher than the spectrum shows, or a lossless file made from a lossy one. This is a suspicion, not proof. Quit Serato before saving a crate.

    Tag spellings

    Whole space

    Pick one spelling per group. Writes the library, not the audio files. Quit Serato first.

    Share anonymous usage stats and crash reports?

    Counts and actions only, plus the app name, the app version, and the operating system. Track titles, crate names, file paths, and library contents stay on this computer. Sharing stays off unless you turn it on.
